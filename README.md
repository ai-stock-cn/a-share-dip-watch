# A股回撤观察

一个部署在 GitHub Pages 的纯静态自选股看板。页面直接获取腾讯行情的最新价格与当日涨跌幅，历史指标由定时快照提供，并按最近完整财年现金分红计算静态股息率。

## 功能

- 默认同步价值看板中的 43 只股票、全部 42 只 A 股银行及用户补充清单，去重后共 115 只
- 输入 6 位代码可重新添加当前 115 只同步股票中的股票
- 自选股保存在浏览器 `localStorage`
- 每次打开页面立即获取最新行情；工作日 9:15–11:30、13:00–15:00 每轮完成后 15 秒自动刷新，其余时段 60 秒；后台标签页暂停，返回页面立即刷新
- 显示每只股票真实报价时间，按北京时间区分“今日行情”“昨日行情”“历史行情”；只有日历昨天使用“昨日”，周末及节假日前数据明确显示历史日期
- 9:25 后拿到当天报价即可显示当天涨跌幅；9:25 前的当天报价标为集合竞价参考，源站未更新时不伪装成今日行情
- 默认按跌幅排序，也可切换为涨幅排序
- 默认每页显示 10 只，可切换为 50 或 100 只并翻页
- 可按当日或近 3 个月累计跌幅筛选 2.5%、3%、4%、5% 以上
- 可筛选今日跌幅是否超过此前近 3 个月的最大单日跌幅
- 股票代码旁显示近 1 年价格轨道：低位、中位或高位及区间位置
- 股票名称链接至雪球个股行情页
- 显示日线、周线、月线 BOLL(20, 2σ) 轨道，并可按周期与下轨、中轨、上轨筛选
- 静态股息率同时显示当前价；近 10 年历史峰值按年度现金分红 / 次年最低周价计算，并显示采用的价格
- 峰值下逐年显示最近 3 年历史股息率及采用的最低周价，按上一年度分红 / 当年最低周价计算
- GitHub Actions 每 15 分钟更新历史指标、分红缓存及备用行情快照；实时价格不依赖 Actions 是否准时执行
- 跌幅达到 3% 显示绿色，达到 5% 显示红色
- 静态股息率 = 最近完整财年税前现金分红 / 当前价

## 数据

浏览器通过 `fetch` 请求 `https://qt.gtimg.cn/`（当前允许 CORS），按 GB18030 解码并将返回文本作为数据解析，不使用 JSONP、`eval` 或第三方可执行脚本，也不需要 API Key。每批最多 80 只股票、整轮超时 10 秒，部分失败时保留对应股票上次报价；手动刷新同样直接获取行情。上游实际报价时间是 `quoteTime`，请求完成时间不会替代报价时间。行情时间未知、交易时段超过 2 分钟未变化、接口失败都会提示；午休和收盘后的当日报价仍显示“今日行情”。工作日时段只是刷新策略，不是交易日历，节假日以实际报价日期判断。

历史 K 线通过腾讯/新浪取得，分红通过东方财富取得，写入同源 JSON。快照与实时行情独立加载，较旧快照不能覆盖较新实时价格。当前价改变时同步重算静态股息率、近 3 月涨幅、价格区间位置、BOLL 位置和下轨距离；BOLL 轨道数值仍由历史快照更新，悬停可见历史数据同步日。历史基准未同步到报价当天时，暂不判断“今日创近 3 月最大跌幅”，以免漏掉昨日数据而误报。

上述行情接口为公开网页接口，更新时间与可用性取决于上游，并非交易所逐笔行情服务；若上游字段或跨域策略变化，页面需要同步调整。旧版快照只有全局行情时间，新生成的快照保存逐股时间；不要把文件生成时间当行情时间。

## 本地运行

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173/`。

## 部署

仓库设置中进入 **Pages**，将部署来源设为 **GitHub Actions**。`Update market data and deploy Pages` 工作流会同步行情、提交数据并直接发布网站。
