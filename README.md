# A股回撤观察

一个部署在 GitHub Pages 的纯静态自选股看板。页面打开时读取最新同步的沪深 A 股当日涨跌幅，并按最近完整财年现金分红计算静态股息率。

## 功能

- 默认同步价值看板中的 43 只股票、全部 42 只 A 股银行及用户补充清单，去重后共 115 只
- 输入 6 位代码可重新添加当前 115 只同步股票中的股票
- 自选股保存在浏览器 `localStorage`
- 每次打开页面读取最新行情，默认按跌幅排序，也可切换为涨幅排序
- 默认每页显示 10 只，可切换为 50 或 100 只并翻页
- 可按当日或近 3 个月累计跌幅筛选 2.5%、3%、4%、5% 以上
- 可筛选今日跌幅是否超过此前近 3 个月的最大单日跌幅
- 股票代码旁显示近 1 年价格轨道：低位、中位或高位及区间位置
- 股票名称链接至雪球个股行情页
- 显示日线、周线、月线 BOLL(20, 2σ) 轨道，并可按周期与下轨、中轨、上轨筛选
- 静态股息率同时显示当前价；近 10 年历史峰值按年度现金分红 / 次年最低周价计算，并显示采用的价格
- 峰值下逐年显示最近 3 年历史股息率及采用的最低周价，按上一年度分红 / 当年最低周价计算
- GitHub Actions 在交易时段每 15 分钟同步一次这 115 只股票的行情
- 跌幅达到 3% 显示绿色，达到 5% 显示红色
- 静态股息率 = 最近完整财年税前现金分红 / 当前价

## 数据

GitHub Actions 通过东方财富公开网页接口生成同源 JSON，页面不直接跨域访问第三方，也不需要 API Key。接口并非正式开放 API，若上游字段或访问策略变化，页面需要同步调整。

## 本地运行

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173/`。

## 部署

仓库设置中进入 **Pages**，将部署来源设为 **GitHub Actions**。`Update market data and deploy Pages` 工作流会同步行情、提交数据并直接发布网站。
