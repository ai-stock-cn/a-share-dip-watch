# A股回撤观察

一个部署在 GitHub Pages 的纯静态自选股看板。页面直接获取腾讯行情的最新价格与当日涨跌幅，历史指标由定时快照提供，并按最近完整财年现金分红计算静态股息率。

## 功能

- 默认显示账号验证页；密码使用 PBKDF2-HMAC-SHA256 带盐校验，可选择在当前浏览器保持登录 30 天
- 默认同步价值看板中的 43 只股票、全部 42 只 A 股银行及用户补充清单，去重后共 153 只
- 输入 6 位代码可重新添加当前 153 只默认股票及资料库中的其他已同步股票
- 每只股票显示企业性质，并支持按企业性质筛选或搜索
- 自选股保存在浏览器 `localStorage`
- 本次从 v8 自选清单升级到 v9 时只追加电投能源，保留已有自选和删除选择；以后手动移除电投能源后不会在刷新时自动恢复
- 每次打开页面立即获取最新行情；工作日 9:15–11:30、13:00–15:00 每轮完成后 15 秒自动刷新，其余时段 60 秒；后台标签页暂停，返回页面立即刷新
- 显示每只股票真实报价时间，按北京时间区分“今日行情”“昨日行情”“历史行情”；只有日历昨天使用“昨日”，周末及节假日前数据明确显示历史日期
- 9:25 后拿到当天报价即可显示当天涨跌幅；9:25 前的当天报价标为集合竞价参考，源站未更新时不伪装成今日行情
- 默认按当前股价距所选周期 BOLL 下轨的有符号百分比升序排序，也可切换为跌幅、涨幅及其他指标排序
- 表格独立显示当前股价，并与当日涨跌幅、静态股息率分列展示；支持按当前股价升序或降序排列
- 表格独立显示周线 BOLL 下轨、中轨和上轨数值，统一保留三位小数
- 默认每页显示 10 只，可切换为 50 或 100 只并翻页
- 可按当日或近 3 个月累计跌幅筛选 2.5%、3%、4%、5% 以上
- 可筛选今日跌幅是否超过此前近 3 个月的最大单日跌幅
- 股票代码旁显示近 1 年价格轨道：低位、中位或高位及区间位置；位置筛选支持同时选择最多两个区间
- 显示截至最新完整报告年度的连续分红年数，并可筛选连续分红 10 年以上的股票
- 可按近 1 年价格轨道位置从低到高或从高到低排序，并可一键重置全部筛选条件与排序
- 股票名称链接至雪球个股行情页
- 显示日线、周线、月线 BOLL(20, 2σ) 轨道，并可按周期与下轨、中轨、上轨筛选；所有位置均显示到下轨的有符号距离，中轨以上同时显示中轨和上轨距离，中轨以下同时显示中轨距离
- 可按当前股价位于周线 BOLL 中轨上方或下方进行独立筛选，并与其他条件同时生效
- 显示日线 BOLL 下轨、中轨、上轨和 MA250 年线；可筛选股价位于年线上方或下方，并按带正负号的年线距离升降序排列
- 静态股息率同时显示当前价；近 10 年历史峰值按年度现金分红 / 次年股息计算价计算，并显示采用的价格
- 峰值下逐年显示最近 3 年历史股息率及采用的计算价，按上一年度分红 / 当年股息计算价计算；旧计算价口径见下文
- 每只股票单独展示近三年最低价（2026 年展示 2024、2025、2026，随年份滚动）；本年注明“年内”，缺少分红也展示；窄屏可横向滚动表格查看
- 每年最低价下显示“现价较低价”的百分比，随实时报价重新计算
- 汇总今年和去年的最低价，显示现价相对近两年最低价的百分比；可按有符号百分比升序或降序排列
- 近两年低价筛选提供“全部”“低于低价（<0%）”“0～+5%”“0～+10%”“0～+20%”，实时报价更新后同步重新计算和筛选
- GitHub Actions 每 15 分钟更新历史指标、分红缓存及备用行情快照；实时价格不依赖 Actions 是否准时执行
- 跌幅达到 3% 显示绿色，达到 5% 显示红色
- 静态股息率 = 最近完整财年税前现金分红 / 当前价

## 数据

浏览器通过 `fetch` 请求 `https://qt.gtimg.cn/`（当前允许 CORS），按 GB18030 解码并将返回文本作为数据解析，不使用 JSONP、`eval` 或第三方可执行脚本，也不需要 API Key。每批最多 80 只股票、整轮超时 10 秒，部分失败时保留对应股票上次报价；手动刷新同样直接获取行情。上游实际报价时间是 `quoteTime`，请求完成时间不会替代报价时间。行情时间未知、交易时段超过 2 分钟未变化、接口失败都会提示；午休和收盘后的当日报价仍显示“今日行情”。工作日时段只是刷新策略，不是交易日历，节假日以实际报价日期判断。

日线历史 K 线通过腾讯取得并由新浪回退，周线 BOLL 优先使用雪球四位小数精度的前复权周收盘价，分红通过东方财富取得，写入同源 JSON。雪球周线接口暂时不可用时自动回退为日线前复权收盘价按周聚合。快照与实时行情独立加载，较旧快照不能覆盖较新实时价格。当前价改变时同步重算静态股息率、近 3 月涨幅、价格区间位置、BOLL 位置和相邻轨道距离；BOLL 轨道数值仍由历史快照更新，悬停可见历史数据同步日。历史基准未同步到报价当天时，暂不判断“今日创近 3 月最大跌幅”，以免漏掉昨日数据而误报。

“近三年最低价”使用新浪不复权日 K 的 `low` 按实际交易日期分年统计，独立保存为 `recentAnnualLowPrices3y`，不依赖分红数据。每年包含 `year`、`price`、最低价首次出现日期 `date`、源数据截至日 `asOf` 和覆盖情况 `coverage`。`recentAnnualLowPricesBasis=unadjusted_daily_low_v1` 标记口径，`recentAnnualLowPricesUpdatedAt` 记录缓存更新时间；缓存最多复用一小时，随后由快照工作流重新获取。当前年显示截至源数据日期的年内最低价，不随每 15 秒的实时报价刷新。只覆盖部分年份时明确显示“区间最低”，缺失年份显示“暂无数据”；获取失败保留原始数据及截至日。悬停可查看最低价日期与统计口径。

“现价较低价” = `(当前价 / 该年显示的低价 - 1) × 100%`，保留两位小数；正数表示现价高于该低价，负数表示低于，相同为 `0.00%`。使用页面当前报价和同为不复权口径的年度低价，每次报价更新时重新计算；旧报价沿用页面的行情日期提示。当前价或低价缺失、非正时显示 `--`。标为“区间最低”的年份使用对应区间低价，历史低价的截至日期保持可见，不把该比例视为含分红的投资收益率。

近两年汇总取北京时间当前自然年和上一自然年的不复权日 K 最低价中较小的一个；例如 2026 年使用 2025、2026 年，本年仍截至历史数据日期。百分比为 `(当前价 / 近两年最低价 - 1) × 100%`，保留正负号和两位小数，随实时报价同步重算。

MA250 使用最近 250 个交易日的前复权收盘价算术平均值，历史数据与 BOLL 同步刷新。年线距离为 `(当前价 - MA250) / MA250 × 100%`，页面保留三位小数；正值表示股价在年线上，负值表示股价在年线下。筛选和排序使用未四舍五入的有符号数值，不取绝对值。

周线 BOLL 使用雪球前复权周 K 的最近 20 个收盘价，按总体标准差计算 `中轨 ± 2σ`。保留四位小数参与距离与排序计算，页面统一显示三位小数；因此与雪球图上保留两位小数的 `UP / MID / LOW` 数值一致，只存在显示位数差异。

升降序和筛选使用未四舍五入的有符号数值，不取绝对值；数值相等时按股票代码排序。两年都必须具备 `full` 覆盖，缺失、任一年为 `partial` 或当前价/低价非正时显示 `--`，在两种排序中均置后，也不参与百分比条件筛选。“低于低价”严格小于 0；三个正向区间均包含 0 和各自上限；“全部”不施加此项筛选。该汇总不会把部分年份的“区间最低”当成完整年度最低价。

旧版 `annualLowPrices10y` 混用了历史周 K 低价和当年前复权最低收盘价，只保留供既有历史股息率计算使用，页面将该价格标为“计算价”。新年度最低价列不读取它，也不以 `recentDividendYields3y.priceUsed` 作为数据来源。

上述行情接口为公开网页接口，更新时间与可用性取决于上游，并非交易所逐笔行情服务；若上游字段或跨域策略变化，页面需要同步调整。旧版快照只有全局行情时间，新生成的快照保存逐股时间；不要把文件生成时间当行情时间。

## 访问验证

登录验证完全在浏览器端执行。仓库只保存 PBKDF2 盐值和不可逆校验值，不保存明文密码；校验参数为 HMAC-SHA256、210,000 次迭代和 256 位输出。勾选“30 天内保持登录”后，本地只保存带到期时间的登录状态，退出登录会立即清除。由于 GitHub Pages 是纯静态托管，熟悉开发者工具的访问者仍可绕过前端界面并直接读取公开资源，因此该功能只适合作为普通访问入口，不等同于服务端鉴权。

## 本地运行

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173/`。

## 部署

仓库设置中进入 **Pages**，将部署来源设为 **GitHub Actions**。`Update market data and deploy Pages` 工作流会同步行情、提交数据并直接发布网站。
